# 共用票單政策

## 票單範圍

- 只取使用者為本次任務指定的票，以及本次 PR 明確關聯的 Jira 票，去重查證
- 不從分支名稱、歷史 commit 或分支歷史加入票

## 主子票對應

- 依 Jira issue type 辨識主票／子任務；主票以自身為資料來源，子任務沿已查證的 parent 找主票，不以一般主票的 parent／Epic 替代
- 保留原關聯票、「子票 → 主票」及資料來源；共用主票可只查一次，不加入兄弟子票、歷史票或其他連結票

## 免票條件

- 無關聯票且實際來源 head 為 `chore`、`refactor`、`chore/<名稱>` 或 `refactor/<名稱>` 時適用；不以 PR 標題、commit 類型或名稱中間的關鍵字判定，不自動改分支取得例外
- 僅免 Jira AC 與修正版本比對，不免審查或其他門檻；有明確關聯票仍須查證，不把查詢失敗當作無票
